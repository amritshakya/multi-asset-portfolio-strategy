# Archive

This directory holds preserved historical artifacts from the original
academic version of this project:

- `original-final.Rmd` — the original R Markdown analysis.
- `final-paper.pdf` — the rendered paper produced from that analysis.

The original analysis contained known look-ahead bias and portfolio-drift
issues, documented in [`docs/methodology-audit.md`](../docs/methodology-audit.md).
Its numbers and exhibits are kept here for reference only and should not be
read as current results.

Current results and methodology live in [`README.md`](../README.md) and
[`docs/rebuilt-methodology.md`](../docs/rebuilt-methodology.md).
